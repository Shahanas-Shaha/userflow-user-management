# UserFlow — User Management App

A modern and responsive user management application built with React, TypeScript, React Router, Context API, and Tailwind CSS.

## 🚀 Features

- View users
- Add new users
- Edit existing users
- Delete users
- Search users by name or email
- View detailed user information
- Client-side form validation
- Loading and error states
- Responsive design
- Global state management with Context API
- API integration with JSONPlaceholder
- Type-safe React components with TypeScript
- Client-side routing with React Router

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Context API
- REST API
- JSONPlaceholder
